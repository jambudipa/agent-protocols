Add `@jambudipa/ag-ui`: AG-UI 1.0 for Effect v4. Effect Schemas for every event
and message of the 1.0 JSON Schema, `AgUiRoute` to serve an agent as a `Stream`
of events, and `AgUiClient` to run one as a decoded, chunk-expanded and verified
`Stream`. Both speak SSE and, through `@jambudipa/ag-ui/proto`, protobuf; both
interoperate with the reference SDK 1.0.4.
